confluence-mcp

MCP server that connects GitHub Copilot to Confluence. 20 tools — read, write, search, crawl, diagram — all from VS Code chat.

GitHub ↗ | Create PAT ↗ | Python 3.10+ MCP v1.0

Quick Start

1. Create a Personal Access Token

Go to your Confluence → Profile → Personal Access Tokens and create a token. No special permissions needed.
URL pattern: https://your-confluence.company.com/plugins/personalaccesstokens/usertokens.action

2. Clone & run setup

git clone https://github.com/your-org/confluence-mcp.git
cd confluence-mcp
.\setup.ps1

If you have SSH configured: git clone git@github.com:your-org/confluence-mcp.git

[1/7] Check Python ≥ 3.10
[2/7] Create virtual environment
[3/7] Install dependencies
[4/7] Ask for your PAT
[5/7] Validate PAT → "Authenticated as: Your Name"
[6/7] Verify server → "20 tools loaded"
[7/7] Auto-inject config into VS Code settings.json

Setup complete.

3. Reload VS Code

Ctrl+Shift+P → Developer: Reload Window. The confluence server appears in your MCP list. Done.

Note: The config is injected into your global VS Code settings. Once set up, it works from any workspace, any directory — you don't need to be inside the confluence-mcp folder.

Why Use This

Keep your repo and Confluence documentation in sync without leaving VS Code.

Write docs from your IDE

Ask Copilot to update or create Confluence pages directly. No browser tab switching, no copy-paste.

Generate diagrams

Have agents generate draw.io diagrams, architecture overviews, or flowcharts and push them straight to Confluence.

Repo ↔ Confluence sync

Made changes in code? Tell Copilot to update the corresponding Confluence page. Documentation stays current with your codebase.

Review & comment

Read Confluence pages for context during code reviews, add comments, and tag pages with labels — all from chat.

CQL Reference

search_confluence accepts Confluence Query Language.

Full-texttext ~ "deployment"
Space filterspace = "SAP" AND type = "page"
Recent changeslastModified > "2025-06-01"
By creatorcreator = currentUser()
By labellabel = "gcp" AND label = "prod"
Title matchtitle ~ "Architecture"

Troubleshooting

Server not showing?

Ctrl+Shift+P → MCP: Reset All Cached MCP Servers, then reload.

Connection error?

Check you're on the corporate network/VPN and your PAT hasn't expired.

SSL warnings?

Expected behind corporate proxy. Uses verify=False by design.

Write tools fail?

Usually proxy/DNS. Run git pull to get the latest fixes.

Architecture

┌─────────────┐    stdio/JSON-RPC    ┌─────────────────┐    HTTPS + PAT    ┌────────────────┐
│  VS Code    │ ◄──────────────────► │  confluence-mcp │ ◄──────────────► │  Confluence    │
│  Copilot    │                      │  server.py      │                  │  Data Center   │
└─────────────┘                      └─────────────────┘                  └────────────────┘

Transport

stdio — VS Code spawns the Python process, communicates via JSON-RPC over stdin/stdout.

Auth

Personal Access Token — Bearer auth against Confluence REST API.

Stack

mcp ≥ 1.0 (FastMCP) + httpx (HTTP client).
